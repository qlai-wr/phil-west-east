# 哲学数字人文项目开发指南

## 核心原则

- **数据准确性**：所有哲学家、核心概念和文本出处必须准确无误，使用标准的英文和中文翻译。
- **可视化至上**：数字人文项目的核心在于直观。D3.js 和 ECharts 的图表必须具备良好的响应式和交互性。
- **界面风格**：采用学术、沉稳的"新古典主义"或"极简主义"视觉风格，背景色建议使用象牙白（#FDFBF7）或宣纸色，搭配深灰色文字。

## 技术规范

- 使用 Next.js 的 App Router 架构。
- 所有的可视化图表组件需封装在 `components/visualizations/` 目录下。
- 哲学家的中英文对照、概念字典、坐标投影数据统一存放在 `data/philosophyData.ts` 中，作为静态数据源驱动页面。
