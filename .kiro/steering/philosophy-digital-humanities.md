# 哲学数字人文项目开发指南

## 核心原则

- **数据准确性**：所有哲学家、核心概念和文本出处必须准确无误，使用标准的英文和中文翻译。
- **可视化至上**：数字人文项目的核心在于直观。D3.js 的图表必须具备良好的响应式和交互性。
- **界面风格**：采用"学术期刊插图"视觉风格——干净但不单调。背景色使用淡灰蓝（#F0F2F5），内容卡片白底带微妙阴影。配色方案：靛蓝色系（#2B4C7E）代表西方哲学，朱砂色系（#C53030）代表中国哲学，古铜金（#B7791F）作为交互强调色。文字分三级：墨色（#1A202C）标题、中灰（#4A5568）正文、浅灰（#A0AEC0）辅助。
- **双语支持**：界面支持中英文切换（通过 LanguageContext 统一管理），每种语言模式下只显示该语言内容，不做双语并列。

## 技术规范

- 使用 Next.js 的 App Router 架构。
- 所有的可视化图表组件需封装在 `src/components/visualizations/` 目录下。
- 语言上下文组件位于 `src/components/LanguageContext.tsx`，通过 `useLanguage()` hook 提供 `lang`、`toggleLang`、`t(zh, en)` 接口。
- 哲学家的中英文对照、概念字典、坐标投影数据统一存放在 `data/philosophyData.ts` 中，作为静态数据源驱动页面。所有 `term` 字段使用 `{ zh: string; en: string }` 结构，`zh` 为纯中文，`en` 为纯英文，不混合。

## 概念网络设计原则

- **演变边（Evolution）**：实线带箭头，表示概念间的主题发展关系（非线性进步），必须尊重历史时序。
- **对照边（Contrast）**：虚线无箭头，表示跨文化的对等映射关系（双向）。
- 每条对照边应有明确的学理依据（如：Being ↔ Dao 均为最高本体论范畴）。
- **中国演变链的历史时序**：先秦道家线（道→无）、先秦儒家线（仁→天人感应）在宋代通过"理"汇合（朱熹综合儒道），再展开为理→气、理→心→良知。绝不可将后代概念"演变"回先代概念。
